Vendored changes (the only ones):

  1. The module import
       import { resolveDshHome } from "@deepseek-ai/dsh-home-paths";
     is replaced by an inline implementation:
       function resolveDshHome() { return process.env.DSH_HOME ?? join(homedir(), ".dsh"); }
     so this package runs outside the DeepSeek Harness host without its
     dependency tree. All storage paths this package uses are injected
     explicitly; the inlined function is only a fallback.

Everything else in the vendored file is byte-identical to the published
bundle. Behavior notes, measurement dates, and issue references in its
comments belong to the upstream project.

WorkBuddy、DeepSeek 均无关联，未获其授权或认可。This package inherits that
scope: it drives the user's own WorkBuddy account on the user's own machine
through the desktop client's unofficial interfaces, without any stability or
compatibility promise.
